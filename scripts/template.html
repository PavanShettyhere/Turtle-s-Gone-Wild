WHEN THINGS GO SIDEWAYS

Debug, learn, repeat.

ROS command or package missing +

Source /opt/ros/jazzy/setup.bash in the current terminal. If installation failed, check Ubuntu version, ROS repository configuration, network access, and apt errors.

The Pi is silent +

For SSH, check the address, boot completion, and enabled SSH service. For ROS discovery, test talker/listener locally first, then check shared domain, subnet discovery, network isolation, and firewall rules. Do not disable the firewall blindly.

Git refuses to push +

Check authentication and the remote URL. If the remote has new commits, fetch and inspect them before merging. Do not force-push over remote work.
